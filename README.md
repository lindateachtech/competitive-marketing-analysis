# Práctica de control de versiones en Power BI

Repositorio de práctica con un informe de Power BI guardado como proyecto (.pbip), para aprender a usar Git y GitHub con Power BI en talleres: commits, ramas, fusiones y pull.

## Qué contiene

- `Competitive Marketing Analysis.pbip`: el archivo que se abre con Power BI Desktop.
- `Competitive Marketing Analysis.Report/`: las páginas y los visuales del informe.
- `Competitive Marketing Analysis.SemanticModel/`: el modelo (tablas, relaciones y medidas) en formato TMDL.
- `.gitignore`: deja fuera los archivos locales de Power BI (`cache.abf` y `localSettings.json`).

## Cómo usarlo

1. Clona el repositorio con VS Code: Ctrl+Mayús+P, Git: Clone, y pega la URL.
2. Abre el archivo `.pbip` con Power BI Desktop.
3. Crea una rama para tus cambios, modifica el informe, guarda y haz commit.
4. Sube tu rama y fusiónala con `main`.

## Requisitos

- Power BI Desktop (versión reciente)
- Git
- Visual Studio Code
- Una cuenta de GitHub

## Notas

Este repositorio es solo para practicar. No subas datos reales ni credenciales.
